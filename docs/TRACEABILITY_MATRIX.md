## 0. PS016 problem statement → code → test → status

The official PS016 statement (course 24SDCS03R) describes GrandVista as having a **global property portfolio** and
asks for **multi-warehouse inventory control and stock reconciliation**. Those lines are mapped first; the rest of the
statement (reservation platform, microservices, gateway, discovery, security, payments, deployment) is covered row by
row in §1 (R1–R22) and summarised at the end of this section. The full statement text is not stored in this
repository, so the rows quote only the phrases above.
